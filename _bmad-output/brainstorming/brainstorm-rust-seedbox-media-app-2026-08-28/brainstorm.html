Technique 01 · First principles thinking

Borehole through two machines

Cut the scripts open. Under apply-stack.py and the leftover reclaim timer there is not a product — there is geology. Surface last. Bedrock first. Then rebuild one machine on the rock so SEEDBOX.md has nowhere to lie.

Drawing 01 · Rebuilt on bedrockScale: 1 operator : 2 hosts

mediaops — a reconciler, not a script runner

desired-state.toml lives in the home repo.
Connection is {host, port, user, auth} — read ~/.ssh/config Host seedbox.
Talk only through an SSH capability: exec, rsync/sftp, optional local-forward.
Port-forward is a debug lens (mediaops ui sonarr), not how daemons talk.

Two Stores (RemoteBuffer, LocalArchive) + optional Grabber. Library of record may run with grabber=None: sync a folder, name it, encode it.

mediaops-coressharrsyncencodeagentcli
PathSchema is the single writer.
Versioned grammar → PathBufs → generated AGENTS.md.
Title identity is TMDB/TVDB/MBID + kind. Folders are a rendered view.
parse(render(id)) == id, or CI fails.

Provider trait: SwizzinBox · AlreadyThere in v1. DockerCompose waits. Version pins first-class (Lidarr 2.14.5 / glibc). EdgeInvariant is law: drift fails reconcile. Copy never walks torrent save paths. Holds are Approve / Reject / Research — not a folder Jellyfin might ingest. AgentTask is a subprocess with a schema, not a brain in-process.

Surface−1−2−3−4−5Bedrock
  1. Playback surface

    Naming is a Jellyfin contract. Chrome and the TV need H.264 8-bit. EncodePolicy(codec, depth, container, hdr) yields Keep, NvencH264, or Refuse.

  2. Pipe

    SSH is the trust boundary and the pipe. nginx URL-bases already are the UI edge. Bulk copy gets its own TCP stream. Cassette fixtures — never require the live box for unit tests.

  3. Matter

    Usenet is deletable after copy. Torrents are not, while they seed. Surplus is not Skip: surplus means the remote may go after local proof.

  4. Mutation

    Installers mutate files; they are not desired state. The panel rewrites nginx. Idempotent apply: run twice is a no-op if Edge, Grab, and Paths already match.

  5. Record

    *arr is a grabber, not the library of record. Local filesystem plus Jellyfin is the record. Identity lives in sqlite: TitleId, path, inode, hash — so a rename does not become a different film.

  6. Tenure

    The seedbox is rented working memory. The home spinning disk is the archive and the playback surface. Desired-state does not live on the disposable box.

  7. Bedrock

    Two machines. One operator. Everything else is a transaction on top of that.

Technique 04 · Failure analysis

From the operator’s history — not folklore

These already happened. The test suite is the scar tissue. Scripts encoded tribal knowledge in comments; the app encodes it in types, generated docs, and a gate that refuses to install a sin.

Incident 01 · Panel Host rewrite

302 to localhost after a panel install

What broke: the public Host became localhost. The edge vanished. The panel wrote nginx like it owned the building.

Lesson: hash nginx app confs for drift. EdgeRepair is one transaction: dry-run a diff, then fix-nginx + apply-stack as a unit.

Incident 02 · ControlMaster starvation

200GiB rsync collapsed other SSH

API calls, doctor, a second shell — all waited on a multiplexed pipe full of a movie.

Lesson: SSH module is two clients. Mux for exec/API. Dedicated TCP for bulk. Never a hope-cron overlap on the same socket.

Incident 03 · HEVC-MP4 Chrome stutter

Dropped frames in the living room

encode_h264.py scanned movies/**/*.mp4 HEVC10 only. Series-skip was an accident. AGENTS.md said 10-bit H.264 would convert. The encoder disagreed.

Lesson: playback matrix in config. Policy packs drive the encoder or docs keep lying. Encode is reversible: .converting, replace, backup-hevc-originals.

Incident 04 · importBlocked holds

Daft Punk Homework, The Who, Yes — sitting

Blocked NZBs posing as library. The junk drawer, unofficial, aging in the dark with an *arr sentence nobody read.

Lesson: Hold is a product. Show the message, ffprobe, age, size. Approve / Reject / Research. Inbox with a TUI, or it becomes a drawer again.

Incident 05 · Lidarr glibc

Click Update. Discover the C library.

A panel button is not a compatibility matrix. Lidarr 2.14.5 is a pin because this OS said so.

Lesson: per-provider OS matrix. upgrade lidarr explains glibc and can refuse. Package updates are transactions, never a click.

Incident 06 · Masked API keys

Test failed on ********

The UI offered asterisks. Someone believed they were a key. Someone pastes them. Someone commits them.

Lesson: presence-boolean, rotate command, never echo. Discover at runtime from config.xml / sabnzbd.ini. Indexers are a set; a duplicate is a conflict, not an append.

Incident 07 · Docs vs code

SEEDBOX.md lied about the scan path

The walker walked one tree. The markdown described another. Agents believed the markdown. Spaces almost happened.

Lesson: mediaops docs render writes human markdown from the same PathSchema structs as the walker. The document cannot drift because it is not authored twice.

Incident 08 · REPACJ leftover names

House.of.the.Dragon S02E07 REPACJ

A scene tag survived into the archive. Lint-later is mopping. Install is the quality gate.

Lesson: strip list is schema, with tests from real sins (REPACJ, REPACK, PROPER). mediaops library lint finds leftover tags and “Season 1” folders. Refuse at the door.

Picture · synthesis

The spine of the machine

This is not an afterthought. The four rooms were excavation. What stands is a reconciler with a clapper for a verb and a grammar for a writer.

01
Nature

A reconciler of desired state across two machines

Not an installer with a sync script taped on. The seedbox is disposable working memory. The home repo holds the document. Wizards are reconciles that you can run twice. apply twice is a no-op if Edge, Grab, and Paths already match.

02
Lens

Port-forward is a debug lens. The API is SSH + localhost HTTP.

mediaops ui sonarr is a session you hold up to the eye. The real remote API is exec and HTTP through a tunnel the process owns. If the home app talks to forwarded ports, a laptop sleep kills apply. That is a product failure mode, already survived.

03
Record

Local filesystem is the library of record. *arr is a grabber.

You tell *arr the truth; you do not ask it what exists. Identity is TitleId, not a path string. The library of record can run with grabber=None. Music remasters do not look like missing albums because MBID is the name of the thing.

04
Writer

PathSchema is the single writer

Generated docs, install gate, agent proposals, Jellyfin contract — one grammar. SEEDBOX.md cannot lie. REPACJ cannot land. Spaces are a refused install. Round-trip parse(render(id)) == id so the year lives in the folder and the file the same way.

05
Verb

Plan is the default verb. Every tribal script is a transaction type.

apply-stack, fix-nginx, encode, reclaim, review, reconcile. Copy, Skip, Review, Unmonitor, DeleteRemote, Encode, Reclaim. Run is plan plus apply. ResourceBudget lives in config: max_copy_gib, min_free_gib, max_nvenc, lock. No magic numbers in source. Jobs have state machines; timers only make-progress-on-ready-jobs.

06
Agents

Typed tools with capability tokens and a title dossier

They propose. Schema writes. Research can be a web-using agent; debug-media a local-file agent; the app only cares about the schema out. Do not give the LLM ssh root. Do not let a vague prompt POST to *arr. Dry-run is the default grant.

07
Scope

v1 is THIS SeedIt4Me/Swizzin box + THIS home disk

Ultra.cc waits behind a trait. Port 2097 is an instance. The empty workspace at /home/coto/work/dev/media-sync becomes the crate of record; ~/videos/_incoming is a deploy target, not the source of truth. CLI-first: TUI and completions are skins. Cron must call the CLI.

08
Jobs that matter

Tonight-playable. Quiet box. Why-isn’t-this-here. Resume-not-restart.

Install and remove tools exist in service of those four. Music-first this week, not more Futurama, is a planner law (later a wants queue). Failure history is the test suite: panel Host, ControlMaster, HEVC-MP4, holds, glibc, masked keys, duplicate indexers, docs vs code.

Title dossier — not the universe

ffprobe · nfo · *arr payload · neighbors
max-bytes budget per task
research this filename → TitleId without downloading
debug this mkv → Direct Play vs transcode against a client profile

Capability tokens

ReadFsProbeMediaArrGet ArrPostSshExecAllowlist ssh root — NEVER

Apply is an explicit grant. Agents get read-only probes by default.
